# 燕子户外 · 智能客服助手

一个面向户外运动场景的智能客服网页应用，内置 DeepSeek 大模型对话 + 12306 车次查询 + 和风天气预报，支持行程规划、装备清单、户外知识库。

## 功能特性

- **智能对话**：DeepSeek 官方直连，支持 Function Calling 工具调用（车次/时刻/比价/天气由模型自动决策调用）
- **火车票查询**：12306 实时车次、余票、时刻表、最便宜中转方案；**12306 被风控/无数据时自动切换「聚合数据」兜底**，保证车次永远查得到
- **天气预报**：和风天气实时 + 24 小时逐时 + 7 天预报 + 日出日落 + 定位查附近天气
- **行程规划**：生成可导出的结构化行程卡
- **装备购物车**：推荐装备一键加入清单，导出完整购买清单
- **户外知识库**：路线规划、露营、饮食、药品、无痕山林、保险、高海拔等 13 个板块

## 快速开始（只需三步）

### 1. 买好 DeepSeek Token（唯一需要你做的付费项）

去 [DeepSeek 开放平台](https://platform.deepseek.com) 充值并生成一个 API Key，把它填进 `index.html` 的 `DEEPSEEK_CONFIG.apiKey` 处即可。

> 车票、天气这些实时数据走的是**本地数据代理**（proxy.py），它内置了和风天气 Key、自动处理 12306 反爬，**你完全不用管、也不用额外花钱**。

### 2. 启动本地数据代理（自动常驻）

双击 `start-proxy.bat`（Windows）。脚本会自动：

- 选择空闲端口（8899 → 8901 → 8902 → 8903 依次尝试）
- 端口全被占用时自动提示并重试
- **代理意外退出后 3 秒自动重启（守护模式）**

> 已配置开机自启（`燕子户外代理.lnk` 在启动文件夹），正常情况开机后代理自动常驻，无需手动启动。

### 3. 打开页面

用浏览器打开 `index.html` 即可。页面会自动发现代理端口，无需手动配置。

## 常见问题（FAQ）

### 问车票/天气提示「本地数据助手未启动」？

说明代理没在运行。双击 `start-proxy.bat` 看到黑色窗口保持打开即可，**无需刷新页面**，直接重新提问会自动连上。

### 提示「检测到本地助手是旧版本」？

说明有旧的代理窗口还在跑（占着端口）。关闭所有旧的黑色命令行窗口，重新双击 `start-proxy.bat`。

### 端口被抖音等其他软件占用怎么办？

脚本会自动换下一个端口，前端也会自动发现新端口，无需任何手动配置。
