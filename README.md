# 燕子户外 · 智能客服助手

一个面向户外运动场景的智能客服网页应用，内置 DeepSeek 大模型对话 + 12306 车次查询 + 和风天气预报，支持行程规划、装备清单、户外知识库。

## 功能特性

- **智能对话**：DeepSeek 官方直连，支持 Function Calling 工具调用（车次/时刻/比价/天气由模型自动决策调用）
- **火车票查询**：12306 实时车次、余票、时刻表、最便宜中转方案
- **天气预报**：和风天气实时 + 24 小时逐时 + 7 天预报 + 日出日落 + 定位查附近天气
- **行程规划**：生成可导出的结构化行程卡
- **装备购物车**：推荐装备一键加入清单，导出完整购买清单
- **户外知识库**：路线规划、露营、饮食、药品、无痕山林、保险、高海拔等 13 个板块

## 快速开始

### 1. 配置 API Key

在项目根目录新建 `config.txt`，填入你的 DeepSeek API Key：

```
sk-xxxxxxxxxxxxxxxxxxxxxxxx
```

同时在 `index.html` 的 `DEEPSEEK_CONFIG.apiKey` 处也填入同一个 Key（前端直连需要）。

> ⚠️ 注意：前端直连会让 Key 暴露在浏览器中，仅适合个人/演示使用；正式上线建议改用后端代理。

### 2. 启动本地数据代理

双击 `start-proxy.bat`（Windows），会自动选择空闲端口启动本地代理，提供 12306 和和风天气数据接口。

### 3. 打开页面

用浏览器打开 `index.html` 即可。

## 项目结构

```

```
